# 小丑牌

一个基于扑克牌型的网页单机游戏，玩法参考 Balatro。用纯 HTML + CSS + JavaScript 实现，无任何依赖，打开即玩。

## 玩法

- 每局目标分 **300 分**，最多出牌 **4 次**、弃牌 **3 次**
- 从手牌（8 张）中选 1–5 张出牌，系统自动识别牌型并计分
- 牌型得分 = (牌型基础分 + 所选牌点数之和) × 倍率
- 达到目标分即胜利，出牌次数耗尽未达标则失败

| 牌型 | 基础分 | 倍率 |
|------|--------|------|
| 皇家同花顺 | 100 | ×8 |
| 同花顺 | 100 | ×8 |
| 四条 | 60 | ×7 |
| 葫芦 | 40 | ×4 |
| 同花 | 35 | ×4 |
| 顺子 | 30 | ×4 |
| 三条 | 30 | ×3 |
| 两对 | 20 | ×2 |
| 对子 | 10 | ×2 |
| 高牌 | 5 | ×1 |

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖或启动服务器。

```bash
open index.html   # macOS
```
